How to Wire a Game (copy-paste)

Add these 3 lines to any game's "Game Over" section:

<!-- 1. Load the engine (once, in <head> or before </body>) -->
<script src="../games/gameEngine.js"></script>

<!-- 2. When the game ends, call saveScore -->
<script>
  // Replace 'body_breath_quest' with your game's id
  // Replace finalScore with your game's actual score variable
  var result = GameEngine.saveScore('body_breath_quest', finalScore);

  // Show level-up screen if they leveled up
  if (result.leveledUp) {
    showLevelUpMessage('Level ' + result.newLevel + '! 🎉');
  }

  // Show badge toasts for any new badges earned
  result.newBadges.forEach(function(badge) {
    showBadgeToast(badge.icon + ' ' + badge.name);
  });

  // Show XP earned on the game-over screen
  document.getElementById('xp-earned').textContent = '+' + result.xpEarned + ' XP';
</script>

That's it. The engine handles everything else — history, streaks, badge checks, level calculation. Copy gameEngine.js to your games/ folder and you're done.
